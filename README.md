# Paper Literature Workflow

面向论文领域的文献工作流技能。先根据目标论文的领域与任务配置检索、筛选和证据规则，再处理文献、比较数据方法并记录选择依据。

当前版本：**0.1.0**。

## 工作模式

| 模式 | 用途 |
|---|---|
| `CONFIGURE` | 形成论文专用来源、检索路线、纳排、精读与比较规则 |
| `PROCESS` | 按授权范围执行整理、筛选、核验、分析集确定及综合 |
| `AUDIT` | 对照规则检查现有文献与过程记录 |
| `COMPARE` | 比较数据方法的必要条件，形成方案建议和未选理由 |

## 安装与调用

将本仓库放到支持项目技能的目录中，目录名保留为 `paper-literature-workflow`。例如：

```text
<project>/.agents/skills/paper-literature-workflow/
```

技能入口为 [SKILL.md](SKILL.md)。调用示例：

> 使用 $paper-literature-workflow，进入 CONFIGURE 模式。根据我的论文领域、研究问题与现有文献资产，形成专用检索、筛选、精读及方法比较方案，并明确已验证与待验证部分。

## 内容

| 目录或文件 | 内容 |
|---|---|
| `SKILL.md` | 触发、模式、流程及边界 |
| `agents/openai.yaml` | 技能界面信息 |
| `references/` | 领域适配、阶段合同、评价选择及行为核验案例 |
| `assets/` | 三个JSON模板与三个CSV模板 |

实例化模板时，将工作文件放入任务目录；保留技能内模板。论文题名、研究问题、地区、年份、文献数量和检索规则均由具体任务配置，不固定在通用技能中。

## 方法边界

- 区分学术相关性、全文获取、分析用途和研究方案采用。
- 按研究类型和预定用途评价，不以期刊声望、获取难易或结果方向自动筛选。
- 区分原始记录、作品、版本、同研究多报告及证据片段。
- 必要条件未知或失败时保留待核，不以总分强行选择方案。
- 遵守所在项目的权限、原始资料保护及正式写作要求。

## 验证状态

已完成技能结构、包内链接、模板解析与列名检查，并进行了单执行者场景自查和少量模拟字段检查。

尚未进行独立行为评测或真实文献集的完整试用；这些检查不代表筛选准确率或研究质量已获验证。该技能是工作流与工具调用指引，不是独立运行的自动文献分类软件。
