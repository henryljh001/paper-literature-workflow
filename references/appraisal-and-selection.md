# 按研究类型评价证据，按问题比较方案

## 质量不是统一等级

| 研究类型 | 核验重点 | 不足时的用途处理 |
|---|---|---|
| 理论与概念 | 出处、定义、假设、推理和边界 | 保留思想史或争论用途；未核原命题不得作为确定依据 |
| 方法与测量 | 对象、操作定义、数据要求、假设、输出和适当验证 | 可作候选或批评对象，不自动认为适用于当前论文 |
| 描述与比较 | 样本或材料、单位、分母、时空一致性及不确定性 | 限定比较范围；单期格局不自动支持演变 |
| 关联分析 | 变量、设计、依赖结构、共同原因与替代解释 | 按实际设计表述关联，不自动宣称因果 |
| 质性与过程 | 材料来源、情境、选择、解释过程、时序或交叉核验及反例 | 说明解释范围，不能机械要求回归或统一统计信度 |
| 干预及效应 | 结果独立性、比较/反事实、识别前提和选择过程 | 未满足因果条件时保留有限的描述、关联或过程用途 |
| 规范与规划 | 价值目标、适用对象、论证、实施与评价状态 | 目标、方案和实际效果分开；规范主张不冒充已验证成效 |

这张表是通用起点，领域方案可细化但不能未经论证设统一分数。报告规范只说明报告应交代什么，不自动证明方法或研究结果正确。

## 精读的最低信息

研究问题、理论框架、设计、抽样/材料及样本特征、数据来源、核心构念与操作化、分析技术、信度/效度或相应可信性策略、主要发现、限制、对当前研究的可借鉴性。每项按适用性填实际内容、原文未报告、未核验或不适用及理由。

相反、零、混合和条件结果不降为低质量标签。全文可读不等于证据足以支撑精确或因果主张；多篇同数据或同研究须记录依赖。

## 三层选择与成文接口

| 层次 | 判断问题 |
|---|---|
| 理论 | 对象与解释关系是什么，前提及可观察含义如何比较 |
| 设计 | 需要什么观测、比较、过程或识别依据才能回答问题 |
| 技术 | 在上述条件下如何测量、编码、计算或估计，怎样验证 |

方法论证模板：

> 为回答【问题】，本研究需要【证据或比较目标】。在【实际已核验条件】下，方案A能够【支持范围】。与方案B相比，A在【与问题直接相关的维度】更适合；B所需的【前提】在本研究中【不满足或不匹配】，故不作本项主方案。A仍受【限制】影响，已通过【实际实施的检查】处理，并将结论限定于【推断范围】。

未完成的验证不能填“已通过”；尚未采用的方案用建议语气。理论、设计和技术可以迭代修订，但须保存原方案及原因。
