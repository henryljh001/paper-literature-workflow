# 七模块的输入、判断与产出

这些是阶段依赖，不要求每次从头运行。模式PROCESS按已授权范围执行，必要时连续跨越已满足依赖的模块；既有项目闸门仍有效。

## 1. INVENTORY：总库整理

输入为允许读取的来源题录、检索导出和身份信息。记录来源批次、路径、日期、原始行ID及可取得的哈希。身份键可缺DOI，但必须留下未核状态。

核对题名、作者、出处和标识后关联独立作品；模糊相似只产生待核候选。同一研究的多篇报告分别保存作品ID，并以研究或依赖关系连接。不得把ID唯一率当作独立作品去重完成。

输出来源记录—作品—版本映射，以及冲突、重复关系与技术排除记录。原始记录不删，分析成员变更另行版本化。

## 2. SCREEN：相关性筛选

输入为有依据的适用规则及原题名、摘要或其他明确材料。题名和摘要可以联合审查。先读内容并判断学术作用，再记录获取状态。

| 阶段决定 | 使用条件 |
|---|---|
| FULLTEXT_TRIGGER | 原文可能支持关键理论、测量、经验关系、过程或反证，需要具体核验 |
| BACKGROUND_ABSTRACT | 摘要足以承担限定的背景、对象尺度或方法谱系说明 |
| AMBIGUOUS_REVIEW | 材料存在但对象、关系或身份仍有实质歧义 |
| METADATA_HOLD | 无有效摘要但尚不能排除学术价值 |
| EXCLUDE_WITH_REASON | 不回答相关问题且无理论、方法、比较、背景或反证贡献 |

每条给出实际内容依据与当前唯一决定；全文触发必须有理由及核验目标。题名、期刊、国家、年份、语言、下载难易及结论方向不得单独决定学术资格。需要按某来源或类型限定研究范围时，必须有预先声明的任务依据，不临时按结果调整。

输出逐记录决定及批次对账。区分输入记录数、作品数和多角色数量；各阶段决定的分母使用同一快照。通用原因码可复用，记录特异性由内容依据和定位保证。

## 3. APPRAISE：原文核验与质量评价

输入为具体核验目标及相应原文、证据卡；背景用途可仅使用足以支撑它的材料。全文未取得单列，不取消原学术判断，也不要求已确认不可得的资料反复索取。

核对对象、单位、时空、材料/数据、方法、发现和边界，记录具体页/节/表。区分作者陈述、执行者推断和实际复算。按 [appraisal-and-selection.md](appraisal-and-selection.md) 判断具体用途：适用、限制使用、待核或不适用。

输出证据记录与用途评价；限制使用须明确限制后可支持的判断。纯理论等字段不适用时说明理由，未知与原文未报告不能混记。

## 4. CORPUS：分析文献集

输入为身份、依据和用途已核对的文献。纳入某集合同时要求：作品身份可用、相关贡献明确、信息满足该分析需要、质量与推断强度适配、用途与定位可追溯。

分别定义计量、背景、理论、方法比较、经验/机制及反证集合。不同集合可以重叠；作品并集不重复计数。储备、其他用途、待核和不适用不统称学术排除；工作池不自动等于实际分析或引用集合。

输出成员清单、纳入依据、未选去向、规则版本及数量说明。冻结是否需要人工批准依当前项目和用户授权；技能不自授权限。

## 5. SYNTHESIZE：跨文献综合

输入为用途明确的证据及其限制。按研究问题/主题比较概念、对象、时空、设计及发现；可比者综合，不可比者分组或作为边界。保留共识、分歧、相反与零结果。

区分检索覆盖缺口、全文缺口、测量不等价、设计不足和真实争论。不能把“本库没找到”写成“从无研究”。输出主张—证据关系及理论/方法/经验综合；不要求每篇都被引用。

## 6. COMPARE：数据方法适用性

输入为问题、文献方法依据和当前任务允许读取的实际可用性证据。按问题、数据版本、测量、方法和验证设计形成候选组合。

必要条件逐项记 `PASS / FAIL / UNKNOWN / NOT_APPLICABLE`，附依据；关键未知不进入无条件可行集合。不适用需解释。数据获取影响本地方案就绪，不反向决定文献相关性。

对可行方案比较效度、覆盖、解释范围、成本和复现条件。确需评分时事前声明尺度、权重和缺失处理；不能以总分抵消必要条件失败。

输出比较表、条件证据、尚缺材料与用途限制，不能把文献中的数据自动记作本论文已拥有。

## 7. SELECT：选取与论证

区分理论选择、研究设计选择及具体技术选择，分别给出前提和替代方案。研究问题数量不固定；一个问题可需要多个互补方法。

输出主要方案建议、备选、未采用理由及推断范围。`ADOPTED`必须对应真实授权或裁决依据，不由完成一份比较表自动推定。没有可行方案时暂缓选定，说明缺什么证据。

向写作交付问题、证据、方法、章节或段落用途的关系及引用定位；正文起草或合并依实际写作权限及用户请求进行。展示机制使用项目适用的制图路径，不自动生成新的研究框架。

## 模板字段约定

所有CSV按UTF-8写入。一个字段含逗号、引号或换行时用标准CSV转义，不手工拼接。表内来源可以是路径、URL、页码或证据ID，但必须足以回查。

`decision_log`追加事件，`is_current`仅标当前问题、用途和阶段的一项活动决定；旧事件通过`supersedes_decision_id`关联。`evidence_record`一行对应一项证据及其明确用途，单篇可有多行；不将行数报告为独立文献数。`method_comparison`一行对应某候选的一项比较条件，用于保留未知和失败。
