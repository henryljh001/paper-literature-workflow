# 工作流行为核验案例

这些是自查及后续独立评测用例，不是已完成测试的声明。实际评测在独立工作目录中运行，保留输入、输出和结论；模拟条目不进入真实文献池。

| 案例 | 给定情况 | 应出现的行为 |
|---|---|---|
| 领域前置配置 | 用户要求按教育质性论文调整通用规则 | 先配置来源、检索路线、纳排和材料/解释字段；不复制某篇地理论文的五个问题或人口指标 |
| 理论原典 | 来源有相关概念贡献，但无回归、样本量或目标地域 | 按理论用途评价；不因缺实证方法或不含题名全部关键词排除 |
| 获取反事实 | 两份完全相同内容仅全文可得性不同 | 学术相关性及内容判断不变；只改变获取或具体用途核验状态 |
| 非预期结果 | 文献报告无显著关联或反向发现 | 按同一学术标准保留或排除，不能因方向不合预期淘汰 |
| 独立作品身份 | 中英文题录ID不同但可能同作 | 核验作品关系；未确认前不声称两条独立证据，也不直接合并 |
| 摘要与承重 | 原文未得但摘要适合背景；用户拟引用精确效应 | 背景可以保留；精确主张进入原文核验或待证 |
| 无可行方案 | 所有候选缺关键观测或识别依据 | 报告不能选定，保留失败/未知，不用总分强行选择 |
| 恢复已完成任务 | 当前状态已完成筛选，仅需审计或指定补证 | 读取有效记录并执行所需范围，不重启广泛检索 |
| 状态冲突 | 恢复卡与权威任务状态不同步 | 停止依赖错误路由；独立规则设计可继续，不自改研究结论或伪造一致 |
| 授权有限 | 请求只比较机制和形成规则 | 产出规则与待核状态，不自动下载、改池、运行实证或写正式主稿 |

结构自查：入口名和描述正确；本地引用均在可访问包内；JSON能解析；CSV列名唯一；模板是未执行状态；无固定文献数量、真实题名、旧RQ或外部绝对路径暗中成为通用条件。

语义自查只能说明执行者核对了指定案例。未真正由独立审阅者运行，不得标为独立评测或声称筛选准确率。真实文献试点另列实际范围与结果。
